
Building Vibration Mode Analyzer

Project Description

The Building Vibration Mode Analyzer is a simple engineering project that demonstrates how eigenvalues and eigenvectors can be used to analyze the vibration behavior of a building.

When a building is subjected to external forces such as wind, machinery, or earthquakes, it can vibrate in different patterns called mode shapes. The natural frequencies of these vibrations can be determined using eigenvalue analysis, while the corresponding eigenvectors represent the vibration mode shapes.

This project provides an interactive way to understand these concepts using a simplified mathematical model of a building.

Objectives

- To understand the application of eigenvalues and eigenvectors in structural engineering.
- To calculate the natural frequencies of a simplified building model.
- To determine the corresponding vibration mode shapes.
- To visualize different vibration modes.
- To connect first-year engineering mathematics with a real-world application.

Mathematical Concept

The project uses the generalized eigenvalue equation:

Kφ = λMφ

Where:

- K = Stiffness matrix
- M = Mass matrix
- λ = Eigenvalue
- φ = Eigenvector or mode shape

The eigenvalues are related to the natural frequencies of the building, while the eigenvectors describe how different floors move during each vibration mode.

Technologies Used

- Python
- Google Colab
- NumPy
- Matplotlib

How It Works

1. A simplified mathematical model of the building is created.
2. Mass and stiffness matrices are defined.
3. Eigenvalues and eigenvectors are calculated.
4. Natural frequencies are obtained from the eigenvalues.
5. The eigenvectors are used to determine the vibration mode shapes.
6. The results are displayed graphically for easy understanding.

Project Output

The analyzer displays the calculated natural frequencies and corresponding vibration mode shapes of the simplified building model.
